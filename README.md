# Nustrim

Nustrim is an Android media client developed by nudroidlabs.

Current capabilities include:

- Stremio catalog, metadata, stream and subtitle addon support
- Cross addon stream resolution
- Yastream compatibility
- CloudStream repository and provider runtime
- Media3 playback with stream headers
- Mobile and TV interface modes
- Local library and playback progress
- Developer diagnostics and provider testing

Android package: `app.nudroidlabs.nustrim`

Current development baseline: `0.26.0-tv-stage7-rc1`

TV mode baseline: fresh `app.nudroidlabs.nustrim.tv` namespace with Home, Details, Sources, Player, Search, Library and Settings implemented.
